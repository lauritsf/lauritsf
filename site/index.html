  2. Semi-Supervised Learning for Molecular Graphs via Ensemble Consensus

    Rasmus H. Tirsgaard, Laurits Fredsgaard, Marisa Wodrich, Mikkel Jordahn, Mikkel N. Schmidt

  3. Same Graph, Different Likelihoods: Calibration of Autoregressive Graph Generators via Permutation-Equivalent Encodings

    Laurits Fredsgaard, Aaron Thomas, Michael Riis Andersen, Mikkel N. Schmidt, Mahito Sugiyama

    AISTATS Workshop: Towards Trustworthy Predictions — Theory and Applications of Calibration for Modern AI.

    Using AutoGraph’s SENT encodings ↗, transformers learn to generate molecular graphs as strings. On QM9, we found that comparing likelihoods across equivalent strings provides a better quality signal than generation likelihood alone.

2026

  1. Calibrated Uncertainty Quantification on TDC ADMET: What Can Be Resolved Across 22 Datasets?

    Laurits Fredsgaard, Michael Riis Andersen, Mikkel N. Schmidt

    AIDaR Workshop at NeurIPS. Camera-ready version forthcoming.

    Across 22 ADMET datasets, we compare eleven calibrated prediction pipelines for accuracy and uncertainty estimates. We test whether the apparent differences between methods hold up across chemical splits, model seeds, and smaller evaluations.

Scientific applications

At LEO Pharma, I extended an existing Django/React application for omics data and built RNA-seq analysis pipelines, working with domain experts on the tools they needed.

For DaSSCo’s digitisation of natural history specimens ↗, I created a Python package for printable Data Matrix labels ↗ for pinned insects and extended existing camera-control and imaging software.

I scaled multi-node training of NequIP and Allegro interatomic potentials on LUMI. I also built boltz-lumi ↗, which adds ROCm kernels for Boltz-2 inference on AMD GPUs.
